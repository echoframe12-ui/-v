## Design Principles

1. **Attest, don't assert.** Claims about shipped capabilities must be backed by executable code, tests, or explicit evidence.
2. **Integrate before expanding.** Existing primitives should be connected before introducing new complexity.
3. **Dissent is data.** Disagreement is preserved as a first-class signal.
4. **Verification precedes consequential action.** The system may plan proactively, but execution remains governed by constitutional and human authorization boundaries.
5. **Context is evidence, not truth.** Larger context improves coverage but does not eliminate uncertainty.
6. **Graceful degradation preserves integrity.** Loss of an optional model, network service, or accelerator must not silently weaken verification guarantees.
7. **Continuous Becoming.** Every verified state is a starting point for the next state; drift and learning remain observable.

## Frontier Roadmap

### Phase 1 — Large-Context Intelligence

Build repository/system context assembly with explicit provenance, bounded context, deterministic ordering, and graceful truncation. Context assembly must remain auditable and must not silently imply that all loaded material is authoritative.

### Phase 2 — Open-Weight Model Adapters

Introduce a provider-neutral adapter boundary for locally hosted and open-weight models. Preserve the same attestation, dissent, confidence, provenance, and fallback semantics used by existing model paths.

### Phase 3 — Proactive Verified Agent Loop

Add a proposal-first loop:

```text
OBSERVE → PREDICT → SIMULATE → PROPOSE → VERIFY → AUTHORIZE → ACT → OBSERVE
```

The default behavior is to prepare and verify actions before execution. High-impact actions require explicit policy or human authorization.

### Phase 4 — Distributed Compute

Only after the preceding layers are stable should the system expand toward distributed and supercomputing-scale execution. Compute scale must increase search and verification capacity without weakening provenance, constitutional controls, or human accountability.
